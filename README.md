**Your Time. Your Control.** — Built by **Ridam Raj**.

## Download Real Android APK

1. Open **[`apk/RR-Reminder.apk`](apk/RR-Reminder.apk)** in this repository and tap **Download raw file** (the **↓** download icon) to save the installable `.apk` directly on Android.
2. Or open the **Releases** tab on the right (or bottom on mobile) and download **`RR-Reminder.apk`** directly under **Assets** (avoid **Code → Download ZIP**, which downloads source code instead of the standalone APK).
3. On Android, open the downloaded `RR-Reminder.apk` and allow installation from your browser/files app if prompted.
