## Download Real Android APK (v2.0)

1. Open **[`apk/RR-Reminder.apk`](apk/RR-Reminder.apk)** in this repository and tap **Download raw file** (the **↓** download icon) to save the installable `.apk` directly on Android.
2. Or open the **Releases** tab on the right (or bottom on mobile) and download **`RR-Reminder.apk`** directly under **Assets**.
3. **Important:** Do **not** click **Code → Download ZIP** — that downloads the source code repository instead of the standalone `.apk` installer.
4. On Android, open the downloaded `RR-Reminder.apk` and allow installation from your browser or Files app if prompted.
